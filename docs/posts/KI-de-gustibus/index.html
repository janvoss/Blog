2 Bildung – ein Grundmodell

Bildung bedeutet, dass wir etwas dazulerenen, dass wir etwas können, was wir vorher noch nicht konnten, dass wir mehr aus unseren Anstrengungen machen können.

Im ökonomischen Kontext ist der Begriff Humankapital üblich geworden, um zu beschreiben, dass jemand produktiver werden/ dazulernen kann. Dieses Humankapital kann bewusst aufgebaut werden oder sich aber als Nebenprodukt anderer Entscheidungen ergeben.

2.1 Lernen als hedonistisches Tun.

2.1.1 Die Entscheidung über Anstrengung in jedem Zeitpunkt

sei \[Y_t=K_t \cdot E_t\], wobei \(Y_t\) das Ergebnis einesr Anstrenung ist (eine glöste Aufgabe, eine geschriebene Hausarbeit, …), \(K_t\) die zu einem bestimmten Zeitpunkt \(t\) vorhandenen Fähigkeiten (das Humankapital) und \(E_t\) die jeweiligen Anstrengungen (effort) bezeichnen.

Das Ergebnis der Anstrengung \(Y\) hat nicht aus sich heraus einen Wert, sondern stiftet Nutzen in Form von Freude, Stolz über das Geleistete, Belohnungen usw. Nehmen wir an, dass wir eine Funktion mit positivem aber abnehmenden Grenznutzen haben \(U(Y_t)=ln(Y_t)\). Man freut sich also über zusätzliche Ergebnisse, aber die zustätzliche Freude wird immer geringer.

Nehmen wir ferner an, dass Anstrengungen tatsächlich anstrengend sind. Anstrengungen führen zu Erschöpfung, Langeweile, usw. Dieser Rückgang an Freude über das Ergebnis durch die Anstrengung habe die Form \(\frac{\theta_E}{2}E^2\). Je mehr das Individuum sich anstrengt, desto erschöpfter ist es und je mehr es sich bereits angestrengt hat, desto größer ist die zusätzliche Erschöpfung.

Der Nettonutzen ist also \[U(K_t, E_t)=ln(K_t \cdot E_t)-\frac{\theta_E}{2}E^2\].

Code 
library(dplyr)

# Parameter definieren

         y = "Nutzen U(K, E)")

Das (statische) Maximierungsproblem lautet \[\max_{E_t} \ln(K_t E_t) - \frac{\theta_E}{2} E_t^2\]

Die Bedingung erster Ordnung ergibt sich durch die partielle Ableitung nach \(E_t\):\[\frac{\partial U}{\partial E_t} = \frac{1}{E_t} - \theta_E E_t = 0 \quad \Rightarrow \quad \theta_E E_t = \frac{1}{E_t}\]

Löst man diese Bedingung nach \(E_t\) auf, zeigt sich ein bemerkenswertes Ergebnis:\[E_t^2 = \frac{1}{\theta_E} \quad \Rightarrow \quad E^* = \frac{1}{\sqrt{\theta_E}}\]

Da dieser Ausdruck unabhängig von \(K_t\) und der Zeit \(t\) ist, wählt das statisch optimierende Indiviuum in jeder Periode ein konstantes Anstrengungsniveau.

2.1.2 Der zufällige Auf- oder Abbau von Humankapital

Bislang haben wir uns nur angeschaut, wie die nutzenmaximierende Menge zu einem bestimmten Zeitpunkt ermittelt wird, wenn ein bestimmtes Niveau von Humankapital gegeben ist und wenn man nur diesen Zeitpunkt betrachtet. Es geht also nur ein momentbezogener hedonistisches Nutzen in die Überlegungen ein.

Humankapital bildet sich bestimmt aus ganz vielen Einflüssen: Genetischer Zufall (Talent), Erziehung, zufällige Erlebnisse. Humankapital bildet sich aber zummindest bestimmt auch durch Anstrengung.

Humankapital verfällt aber auch mit der Zeit. Man vergisst Erlerntes oder kommt aus der Übung. Oder das Wissen veraltet, weil es technischen und wissenschaftlchen Fortschritt gibt.

Beide Aspekte lassen sich so abbilden. Die Veränderung des Humankapitals (\(\dot{K}_t\)) ergibt sich aus dem Humankapitalaufbau durch Anstrengung (\(E_t\)) und dem Abbau durch Abschreibung (Vergessen, Veralten) \(\delta K_t\):

\[\frac{\mathrm{d}K_t}{\mathrm{d}t} \equiv \dot{K}_t = E_t - \delta K_t\]

Solange die aktuelle Anstrengung ausreicht, um die Abschreibungen mindestens aufzuwiegen, bleibt das Humankapital erhalten oder wächst sogar. Wenn jedoch die Anstrengungen dazu nicht ausreichen, verfällt das Humankapital. Wenn sich die beiden Effekte auf das Humankapital genau aufheben, gibt es keine Veränderung mehr (steady state) \[\dot{K}_t = 0 \iff E_t = \delta K_t\].

Setzt man hier den Steady State für die Anstrengung \(E^*\) ein, ergibt sich ein Steady State für das Humankapital: \[K^* = \frac{E^*}{\delta} = \frac{1}{\delta \sqrt{\theta_E}}\]

Je nach anfänglichem \(K_0\), der Abschreibungsrate \(\delta\) und den (emotionalen) Kosten der Anstrengung \(\theta_E\) kann durch das beiläufige Lernen, das aus der Wahl einer Anstrengung im Zusammenhang mit einer statischen Nutzenmaximierung erfolgt, zu einem Anstieg oder zu einer Erosion des Humankapitals führen.

Code 
library(tidyverse)

# ==============================================================================
# 1. Modellparameter & Startwerte
# ==============================================================================
i_val   <- 0.05    # Diskontsatz für die Gegenwartswert-Integration
theta_E <- 1.0     # Parameter des Arbeitsleids
delta   <- 0.05    # Abschreibungsrate des Humankapitals
K_0     <- 2.0     # Startkapital zum Zeitpunkt t = 0
T_max   <- 60      # Simulationshorizont
dt      <- 0.5     # Zeitraster für die Trapezintegration

# ==============================================================================
# 2. Lagrange-Optimierung & Kumuliertes Nutzenintegral W(t)
# ==============================================================================
E_L <- 1 / sqrt(theta_E)

df_lagrange <- data.frame(time = seq(0, T_max, by = dt)) %>% 
  mutate(
    # Starre Anstrengung des myopischen Agenten
    E = E_L,
    
    # Analytischer Pfad des Humankapitals
    K = K_0 * exp(-delta * time) + (E_L / delta) * (1 - exp(-delta * time)),
    
    # Output
    Y = K * E,
    
    # 1. Diskontierter Periodennutzen (Flussgröße)
    U_flow = exp(-i_val * time) * (log(Y) - (theta_E / 2) * E^2),
    
    # 2. INTEGRAL / KUMULIERTE WOHLFAHRT W(t) via Trapezregel/cumsum (Bestandsgröße)
    U = cumsum((U_flow + lag(U_flow, default = U_flow[1])) / 2 * dt)
  )

# ==============================================================================
# 3. Datenaufbereitung & Visualisierung
# ==============================================================================
df_long <- df_lagrange %>% 
  pivot_longer(cols = c(K, E, Y, U), names_to = "Variable", values_to = "Wert") %>% 
  mutate(Variable = factor(Variable, levels = c("K", "E", "Y", "U")))

facet_labels <- c(
  K = "Humankapital (K)",
  E = "Eigene Anstrengung (E)",
  Y = "Output (Y)",
  U = "Kumulierte Wohlfahrt W(t) [Integral]"
)

  facet_wrap(~ Variable, scales = "free_y", ncol = 2,
             labeller = as_labeller(facet_labels)) +

    title = "Dynamik des Lagrange-Agenten mit kumulierter Wohlfahrt",
    subtitle = expression(paste("Das Nutzenintegral ", W(t) == int(exp(-i*s)*U(s)*ds, 0, t), " flacht asymptotisch gegen das Gesamtpotenzial ab")),
    x = "Zeit (t)",

2.2 Lernen als zielgerichteter Prozess

Die Akkumulation oder Erosion von Humankapital ist bislang rein zufällig erfolgt, sie ist das Nebenprodukt einer momentanen Nutzenmaximierung. Diese Zufälligkeit hat in der Lebenswirklichkeit bestimmt ihren Platz. Beispielsweise kann man wandern gehen, um die Landschaft und die Bewegung zu genießen und baut nebenher körperliche Fitness und geografische Orientierungsfähigkeit auf. Man kann ins Theater gehen, um sich für einen Abend unterhalten zu lassen und erlangt nebenher Wissen über Literaturgeschichte, Schauspieltechniken und das Modeempfinden der anderen Zuschauer. Man kann ein neues Rezept ausprobieren, weil man eine schmackhafte Mahlzeit zubereiten möchte und lernt nebenher neue Zutaen undKochtechniken kennen usw.

Diese Zufälligkeit ist aber unbefriedigend für die Beschreibung eines zielgerichteten Bildungsprozesses. Wenn die heutige Anstrengung nicht nur zu höheren Output und höherem Arbeitsleid heute führt, sondern auch die Bedingungen beeinflusst, unter denen in der Zukunft Output erzeugt werden kann, dann sollte dies auch in dem Optimierungskalkül berücksichtigt werden.

Es müsste also nicht mehr die Anstrengung zu einem Zeitpunkt optimiert werden, sondern ein ganzer Zeitpfad der Anstrengung, in dessen Verlauf die Wirkung heutiger Handlungen auf den Nutzen heute und die zukünftige Produktivität berücksichtigt wird.

Hierbei soll berücksichtigt werden, dass künftige Ereignise mit einem geringeren Gewicht bewertet werden als heutige. Dies geschieht, indem (ausgehend von der Gegenwart \(t=0\)) jedes Ereignis mit \(e^{-\rho t}\) diskontiert wird. Für \(t=0\) ist diess Gewicht gleich \(1\). Je weiter ein Ereignis in der Zukunft liegt, desto geringer wird es gewichtet. Hier wird von einem im Prinzip unendlich langen Planungshorizont ausgegangen. Allerdings haben Ereignisse in der fernen Zukunft nur einen sehr geringen Einfluss uud das heutige Nutzenniveau. Die Annahme ist also zunächst einmal nicht zu problematisch.

Ein über den Zeitpfad optimierendes Individuum wählt den Zeitpfad seiner Anstrengung \(E_t\), um seinen über einen unendlichen Zeithorizont diskontierten Gesamtnutzen zu maximieren. Die exogene Zeitpräferenzrate (Diskontrate) des Agenten ist \(\rho > 0\). Das intertemporale Optimierungsproblem lautet:

\[\max_{E_t} \int_{0}^{\infty} e^{-\rho t} \left( \ln(K_t E_t) - \frac{\theta_E}{2} E_t^2 \right) dt\]

unter der Nebenbedingung \[\dot{K}_t = E_t - \delta K_t\] sowie gegebenem Anfangskapital \(K_0 > 0\).

Zur Lösung dieses Problems formulieren wir die zugehörige Hamilton-Funktion 1.

\[\mathcal{H} = \ln(K_t E_t) - \frac{\theta_E}{2} E_t^2 + \mu_t (E_t - \delta K_t)\]

Dabei bezeichnet \(\mu_t\) den dynamischen Schattenpreis des Humankapitals. Es ist der Grenznutzen des Humankapitals und zeigt den gegenwärtigen Gesamtwert, den eine zusätzliche Einheit Humankapital (\(K_t\)) für die gesamte verbleibende Zukunft des Individuums stiftet. Innerhalb der Hamilton-Funktion verknüpft er die beiden Summanden, von denen der erste Nutzen ausdrückt, die Klammer im zweiten jedoch nur die Entwicklung des Humankapitals. Durch \(\mu_t\) wird der Wert es Humankapitals in „Nutzeneinheiten” umgerechnet und somit zum ersten Teil addierbar gemacht.

Die Hamilton-Funktion besteht aus zwei Teilen. Der erste Teil enthält das bekannte statische Optimierungsproblem. Der zweite Teil beinhaltet die Berücksichtigung der Dynamik: Durch die Wahl von \(E_t\) wird die Entwicklung von \(K_t\) beeinflusst.

2.2.1 Bedingung für die Kontrollvariable (Anstrengung)

Die Bedingungen erster Ordnung für einen inneren Lösungs-Pfad ergeben sich aus der Ableitung nach der Kontrollvariablen \(E_t\) sowie der Bewegungsgleichung für den Schattenpreis \(\mu_t\):

\[\frac{\partial \mathcal{H}}{\partial E_t} = 0 \quad \Rightarrow \quad \frac{1}{E_t} - \theta_E E_t + \mu_t = 0\]

Umgestellt nach dem Schattenpreis ergibt sich:

\[\mu_t = \theta_E E_t - \frac{1}{E_t}\]

Diese Gleichung zeigt den zentralen Trade-off: Der Schattenpreis \(\mu_t\) entspricht dem Grenzarbeitsleid der Anstrengung (\(\theta_E E_t\)) abzüglich des direkten Grenznutzens aus dem aktuellen Output (\(1/E_t\)).

2.2.2 Euler-Gleichung (Bewegung des Schattenpreises)

\[\dot{\mu}_t = \rho \mu_t - \frac{\partial \mathcal{H}}{\partial K_t} \quad \Rightarrow \quad \dot{\mu}_t = \rho \mu_t - \left( \frac{1}{K_t} - \mu_t \delta \right)\]

Zusammengefasst beschreibt diese Differentialgleichung die Dynamik des Schattenpreises über die Zeit:2

\[\dot{\mu}_t = (\rho + \delta) \mu_t - \frac{1}{K_t}\]

2.2.3 Konvergenz von \(E\), \(K\) und \(\mu\)

Um die Entwicklung der Anstrengung \(E_t\) in Abhängigkeit vom Humankapitalstock \(K_t\) darzustellen, eliminieren wir den Schattenpreis \(\mu_t\). Dazu leiten wir die Optimalitätsbedingung \(\mu_t = \theta_E E_t - \frac{1}{E_t}\) nach der Zeit \(t\) ab:\[\dot{\mu}_t = \theta_E \dot{E}_t + \frac{1}{E_t^2} \dot{E}_t = \left( \theta_E + \frac{1}{E_t^2} \right) \dot{E}_t\]

Setzen wir diesen Ausdruck sowie die Gleichung für \(\mu_t\) in die Euler-Gleichung \(\dot{\mu}_t\) ein, erhalten wir:\[\left( \theta_E + \frac{1}{E_t^2} \right) \dot{E}_t = (\rho + \delta) \left( \theta_E E_t - \frac{1}{E_t} \right) - \frac{1}{K_t}\]

Aufgelöst nach \(\dot{E}_t\) ergibt sich zusammen mit der Zustandsgleichung des Humankapitals ein autonomes, zweidimensionales Differentialgleichungssystem, das die zeitliche Entwicklung von Kapitalstock und Anstrengung vollständig beschreibt:\[\dot{K}_t = E_t - \delta K_t\]

\[\dot{E}_t = \frac{(\rho + \delta) \left( \theta_E E_t - \frac{1}{E_t} \right) - \frac{1}{K_t}}{\theta_E + \frac{1}{E_t^2}}\]

Das System konvergiert entlang eines Sattelpfades in ein langfristiges stationäres Gleichgewicht (Steady State), in dem sich weder der Kapitalstock noch die Anstrengung weiter verändern (\(\dot{K}_t = 0\) und \(\dot{E}_t = 0\)).

Aus der Stationaritätsbedingung des Kapitals (\(\dot{K}_t = 0\)) folgt unmittelbar \[E^* = \delta K^* \quad \Rightarrow \quad K^* = \frac{E^*}{\delta}\]

In einem stationären Zustand der Anstrengung (\(\dot{E}_t = 0\)) muss der Zähler der Differentialgleichung für \(\dot{E}_t\) null werden:\[(\rho + \delta) \left( \theta_E E^* - \frac{1}{E^*} \right) - \frac{1}{K^*} = 0\]

Setzen wir die Gleichgewichtsbedingung \(K^* = E^* / \delta\) ein und multiplizieren die Gleichung mit \(E^*\), ergibt sich:\[(\rho + \delta) \left( \theta_E (E^*)^2 - 1 \right) - \delta = 0\]

\[(\rho + \delta) \theta_E (E^*)^2 = \rho + 2\delta\]Daraus resultieren die expliziten, konvergierenden Gleichgewichtswerte für die optimale Anstrengung \(E^*\) und das langfristige Humankapital \(K^*\):\[E^* = \sqrt{\frac{\rho + 2\delta}{\theta_E (\rho + \delta)}}\]

\[K^* = \frac{E^*}{\delta} = \sqrt{\frac{\rho + 2\delta}{\theta_E \delta^2 (\rho + \delta)}}\]

Je geduldiger der Agent ist (je kleiner die Diskontrate \(\rho\)), desto höher liegt das Anstrengungsniveau \(E^*\), gegen das das System konvergiert, und desto massiver ist der langfristig gesicherte Humankapitalstock \(K^*\).

Wenn man davon ausgeht, dass die Parameter \(\theta_E\), \(\delta\) und \(\rho\) individuell unterschiedlich sein können, dann können diese Parameter Unterschiede im individuellen Lernerfolg, d.h. im Aufbau von Humankapital, erklären. Über die subjektiven Arbeitsbedingungen und die subjektive Mühe des Lernens (\(\theta_E\)), die Vergesslichkeit oder Kurzlebigkeit des Gelernten (\(\delta\)) oder die Geduld bzw. die langfristigkeit des Planungshorizontes (\(\rho\)) zu sprechen ist vermutlich einfacher als über so komplizierte Ideen wie Talent, Begabung oder Intelligenz.

Die folgende Abbildung zeigt die Auswirkung unterschiedlicher Diskontraten \(\rho\).

Code 
library(tidyverse)

# ==============================================================================
# 1. Globale Modellparameter
# ==============================================================================
theta_E <- 1.0     # Parameter des Arbeitsleids
delta   <- 0.05    # Abschreibungsrate des Humankapitals
K_0     <- 2.0     # Startkapital zum Zeitpunkt t = 0
T_max   <- 60      # Simulationshorizont
dt      <- 0.5     # Schrittweite der Zeitreihe

i_low   <- 0.02    # Niedriger Diskontsatz (hohe Geduld)
i_high  <- 0.20    # Hoher Diskontsatz (hohe Ungeduld)

# ==============================================================================
# 2. Hilfsfunktion mit kumuliertem Nutzen-Integral W(t)
# ==============================================================================
sim_hamilton <- function(i_val, label) {
  times <- seq(0, T_max, by = dt)
  
  E_star <- sqrt((i_val + 2 * delta) / (theta_E * (i_val + delta)))
  K_star <- E_star / delta
  
  beta    <- theta_E + 1 / (E_star^2)
  det_J   <- -delta * (i_val + delta) - 1 / (beta * K_star^2)
  lambda  <- (i_val - sqrt(i_val^2 - 4 * det_J)) / 2
  slope_E <- lambda + delta
  
  data.frame(time = times) %>% 
    mutate(
      K      = K_star + (K_0 - K_star) * exp(lambda * time),
      E      = E_star + slope_E * (K - K_star),
      Y      = K * E,
      
      # 1. Diskontierter Periodennutzen (Flussgröße)
      U_flow = exp(-i_val * time) * (log(Y) - (theta_E / 2) * E^2),
      
      # 2. INTEGRAL / KUMULIERTE WOHLFAHRT W(t) via Trapezregel/cumsum (Bestandsgröße)
      # Numerische Approximation: Integral_0^t exp(-i*s)*U(s) ds
      U      = cumsum((U_flow + lag(U_flow, default = U_flow[1])) / 2 * dt),
      
      Typ    = label
    )
}

# ==============================================================================
# 3. Daten zusammenführen & Visualisieren
# ==============================================================================
df_hamilton <- bind_rows(
  sim_hamilton(i_low,  "Geduldig (niedriger Diskontsatz: i = 0.02)"),
  sim_hamilton(i_high, "Ungeduldig (hoher Diskontsatz: i = 0.20)")
)

df_long <- df_hamilton %>% 
  pivot_longer(cols = c(K, E, Y, U), names_to = "Variable", values_to = "Wert") %>% 
  mutate(Variable = factor(Variable, levels = c("K", "E", "Y", "U")))

facet_labels <- c(
  K = "Humankapital (K)",
  E = "Eigene Anstrengung (E)",
  Y = "Output (Y)",
  U = "Kumulierte Wohlfahrt W(t) [Integral]"
)

ggplot(df_long, aes(x = time, y = Wert, color = Typ, linetype = Typ)) +
  geom_line(linewidth = 1.2) +
  facet_wrap(~ Variable, scales = "free_y", ncol = 2,
             labeller = as_labeller(facet_labels)) +
  scale_color_manual(values = c(
    "Geduldig (niedriger Diskontsatz: i = 0.02)" = "#1b9e77",
    "Ungeduldig (hoher Diskontsatz: i = 0.20)"  = "#e74c3c"
  )) +
  scale_linetype_manual(values = c("solid", "dashed")) +

    title = "Dynamik des Hamilton-Agenten mit kumulierter Wohlfahrt",

2.3 Das Mindestoutput-Niveau als paternalistische Maßnahme gegen zu geringe Leistung

Wenn das Leistungsniveau unterhalb einer exogenen Erwartung bleibt (etwa den erwarteten Leistungen in einem Studiengang), kann ein Mindestoutputniveau \[Y_t \ge \bar{Y}\] vorgebeben werden. Diese Maßnahme zwingt ein Individuum dazu sich anzustrengen, durch die Wahl von \(E_t\) bei gegebenem \(K_t\) das Mindestniveau zu erreichen. Das Ergebnis ist nicht mehr nutzenmaximierend, sodass man begründen müsste, warum ein Individuum sich diesem Zwang unterwerfen möchte.

Diese Restriktion kann auf zweierlei Weise wirken. Wenn ein Individuum seinen Steady State in \(E\) und \(K\) noch nicht erreicht hat, dann kann die Vorgabe eines Mindestoutputs \(\bar{Y}\) den Weg zum Steady State beschleunigen. Wenn der Output im Steady State kleiner ist als der Mindestoutput, \(Y(K^*, E^*)< \bar{Y}\), dann kann die Leistung im Steady State erhöht werden, zumindest, solange ein Individuum den Mindestoutput erreichen muss. Die Vorgabe eines Mindestoutputniveaus führt nicht nur zu kurzfristigen Anstrengungen, sondern tatsächlich auch zum Aufbau und Erhalt von Humankapital zumindest für den Zeitraum, für den die Restriktion bindet. Fällt diese Restriktion weg, konvergiert der Output wieder gegen \(Y(K^*, E^*)< \bar{Y}\).

Unter der externen Vorgabe muss gelten \(K\cdot E = \bar{Y}\). Im Steady State unter der externen Vorgabe gilt \(\dot{K}=0\) also \(\bar{E}^*=\delta \bar{K}^*\). Daher gilt \[\bar{K}^*=\sqrt{\frac{\bar{Y}}{\delta}}\] und \[E^* = \delta \cdot \sqrt{\frac{\bar{Y}}{\delta}} = \sqrt{\frac{\delta^2 \cdot \bar{Y}}{\delta}} = \sqrt{\delta \cdot \bar{Y}}\]

2.4 Der Effekt von KI auf eigene Anstrengung und den Aufbau von Humankapital

Mit der breiten Verfügbarkeit generativer KI-Modelle ändert sich die Produktionsfunktion des kognitiven Outputs fundamental. KI ermöglicht es einem Individuum, kognitive Aufgaben zu delegieren, also kognitiven Output zu erzeugen, der nicht einer eigenen kognitiven Anstrengung entstammt .

Wir modellieren die KI-Nutzung \(A_t\) als perfektes Substitut zur eigenen Anstrengung \(E_t\) bei der unmittelbaren Output-Generierung. Hierbei wird unterstellt, dass das bereits vorhandene Humankapital \(K_t\), auch auf die Nutzung von KI-Diensten wirkt: Ein Individuum mit hohem Fachwissen kann die KI-Dienste produktiver einsetzen als ein Novize. Die modifizierte Produktionsfunktion lautet:

\[Y_t = K_t (E_t + A_t)\]

Die Integration der KI erweitert den Handlungsraum des Agenten, verändert aber auch die Struktur des Arbeitsleids. Wir nehmen an, dass die Nutzung von KI-Diensten zwar eine gewisse kognitive Belastung (z. B. Formulierung von Prompts, Überprüfung auf Plausibilität) mit sich bringt, diese jedoch strikt geringer ist als die klassische Anstrengung ohne KI: \(\theta_E > \theta_A\). Die modifizierte Nutzenfunktion lautet:

\[U(Y_t, E_t, A_t) = \ln(K_t (E_t + A_t)) - \frac{\theta_E}{2} E_t^2 - \frac{\theta_A}{2} A_t^2\]

Die Restriktion der Wissensakkumulation bleibt unverändert: Die KI lernt nicht für das Individuum. Nur eigene Anstrengung baut Humankapital auf:

\[\dot{K}_t = E_t - \delta K_t\]

Das neue Optimierungsproblem des Agenten besteht nun in der simultanen Wahl der optimalen Pfade für \(E_t\) und \(A_t\). Die Hamilton-Funktion erweitert sich zu:

\[\mathcal{H} = \ln(K_t(E_t + A_t)) - \frac{\theta_E}{2} E_t^2 - \frac{\theta_A}{2} A_t^2 + \mu_t (E_t - \delta K_t)\]

2.4.1 Die Bedingungen erster Ordnung und die Substitutionslogik

Die simultane Optimierung über die beiden Kontrollvariablen liefert Bedingungen erster Ordnung für einen inneren Lösungs-Pfad:

  1. Nachfrage nach KI-Delegation (\(A_t\)):

\[\frac{\partial \mathcal{H}}{\partial A_t} = 0 \quad \Rightarrow \quad \frac{1}{E_t + A_t} - \theta_A A_t = 0 \quad \Rightarrow \quad \theta_A A_t (E_t + A_t) = 1\]

  1. Nachfrage nach eigener Anstrengung (\(E_t\)):

\[\frac{\partial \mathcal{H}}{\partial E_t} = 0 \quad \Rightarrow \quad \frac{1}{E_t + A_t} - \theta_E E_t + \mu_t = 0\]

Setzt man die Bedingung für die KI-Nachfrage (\(\frac{1}{E_t+A_t} = \theta_A A_t\)) in die Bedingung für die eigene Anstrengung ein, offenbart sich die zentrale ökonomische Substitutionslogik des Modells:

\[\mu_t = \theta_E E_t - \theta_A A_t\]

Der Schattenpreis des Wissens (\(\mu_t\)) entspricht in jedem Zeitpunkt der Differenz der marginalen Disutilitäten zwischen eigener kognitiver Arbeit und KI-Delegation. Diese Gleichung steuert die Aufteilung: Wenn der Agent sein Humankapital intertemporal hoch bewertet (hohes \(\mu_t\)), nimmt er freiwillig ein höheres Grenzleid beim Lernen in Kauf und wählt \(E_t > A_t\).

Die Euler-Gleichung für die Bewegung des Schattenpreises bleibt strukturell identisch zum Basismodell, da der Grenznutzen des Kapitals (\(\frac{\partial \mathcal{H}}{\partial K_t} = \frac{1}{K_t}\)) von der Aufteilung zwischen \(E_t\) und \(A_t\) unberührt bleibt:

\[\dot{\mu}_t = (i + \delta) \mu_t - \frac{1}{K_t}\]

2.4.2 Die sanfte KI-Falle bei myopischem Verhalten

Das Vorhandensein der KI (\(A_t > 0\)) verändert die Konsequenzen einer hohen Diskontrate \(i\) drastisch. Im klassischen Modell ohne KI war der ungeduldige Agent durch den vollständigen Output-Ausfall gezwungen, zumindest ein minimales Niveau an \(E_t\) aufrechtzuerhalten.

In der KI-Ökonomie hingegen bietet sich dem myopischen Agenten ein bequemer Ausweg. Da er die Zukunft stark diskontiert, sinkt der Schattenpreis \(\mu_t\) auf ein sehr niedriges Niveau. Gemäß der Substitutionsbedingung (\(\theta_E E_t = \theta_A A_t + \mu_t\)) verschiebt sich das Gleichgewicht massiv zugunsten der KI-Nutzung, da die eigene Anstrengung teurer ist (\(\theta_E > \theta_A\)).

Für hinreichend hohe Diskontraten fällt die freiwillig gewählte Eigenleistung \(E_t\) vom ersten Tag an unter die Abschreibungsgrenze:

\[E_t < \delta K_t\]

Dies markiert den Eintritt in die sanfte KI-Falle:

  1. Schleichende kognitive Erosion: Das Humankapital erodiert glatt und kontinuierlich (\(\dot{K}_t < 0\)), anstatt abrupt abzustürzen.
  2. Die Kompensationsspirale: Da das Wissen \(K_t\) schrumpft, wird die Effizienz der KI-Nutzung geringer. Um den Nutzenabfall zu bremsen, muss der Agent proportional immer mehr Aufgaben an die KI delegieren (\(A_t\) steigt relativ zu \(E_t\)).
  3. Stagnation im Dilettantismus: Das System konvergiert gegen einen Steady State mit minimalem Humankapital \(K^*\), in dem der Agent dauerhaft den Großteil seines kognitiven Budgets aufwenden muss, um die KI zu steuern und zu korrigieren, ohne selbst noch nennenswertes Wissen zu generieren.

Die KI ermöglicht es dem ungeduldigen Agenten somit, den kognitiven Schmerz der Gegenwart zu Lasten einer strukturellen, irreversiblen Dequalifizierung in der Zukunft zu minimieren.

# ------------------------------------------------------------------------------
# ENGINE A: MIT KI (Freie Optimierung über Sattelpfad)
# ------------------------------------------------------------------------------
get_EA_free <- function(mu, t_E, t_A) {
  a <- t_E * (t_E + t_A)
  b <- -mu * (2 * t_E + t_A)
  c <- mu^2 - t_A
  disc <- b^2 - 4 * a * c
  E <- (-b + sqrt(disc)) / (2 * a)
  A <- (t_E * E - mu) / t_A
  list(E = E, A = A)
}

sim_KI_free <- function(i_val, label, T_max = 30) {
  ss_eq <- function(mu) get_EA_free(mu, theta_E, theta_A)$E - (delta / ((i_val + delta) * mu))
  mu_star <- uniroot(ss_eq, interval = c(0.001, 10))$root
  K_star  <- 1 / ((i_val + delta) * mu_star)

  dE_dmu <- (get_EA_free(mu_star + 1e-6, theta_E, theta_A)$E - get_EA_free(mu_star, theta_E, theta_A)$E) / 1e-6
  J <- matrix(c(-delta, 1/(K_star^2), dE_dmu, i_val + delta), nrow = 2)
  ev <- eigen(J)
  beta <- (ev$values[which(ev$values < 0)] - (-delta)) / dE_dmu

  ode_model <- function(t, state, parms) {
    K <- state["K"]
    mu <- mu_star + beta * (K - K_star)
    dK <- get_EA_free(mu, theta_E, theta_A)$E - delta * K
    list(c(dK))
  }

  out <- ode(y = c(K = K_0), times = seq(0, T_max, by = 0.1), func = ode_model, parms = NULL)
  df <- as.data.frame(out) %>% mutate(mu = mu_star + beta * (K - K_star), Typ = label, KI = "Mit KI")
  ea <- lapply(df$mu, get_EA_free, t_E = theta_E, t_A = theta_A)
  df$E <- sapply(ea, `[[`, "E"); df$A <- sapply(ea, `[[`, "A")
  df$X <- df$E + df$A; df$Y <- df$K * df$X
  df$U <- log(df$Y) - 0.5 * theta_E * (df$E^2) - 0.5 * theta_A * (df$A^2)
  return(df)
}

# ------------------------------------------------------------------------------
# ENGINE B: KORRIGIERT (Mit KI, Mindestoutput Y_bar & echter Vorausschau)
# ------------------------------------------------------------------------------
sim_KI_Ybar_true <- function(i_val, label, T_max = 30) {

  get_E_constr <- function(K, mu) {
    (theta_A / (theta_E + theta_A)) * (Y_bar / K) + (mu / (theta_E + theta_A))
  }
  get_A_constr <- function(K, E) {
    (Y_bar / K) - E
  }

  dK_dt <- function(K, mu) {
    get_E_constr(K, mu) - delta * K
  }

  dmu_dt <- function(K, mu) {
    E <- get_E_constr(K, mu)
    A <- get_A_constr(K, E)
    (i_val + delta) * mu - theta_A * A * (Y_bar / (K^2))
  }

  ss_eq <- function(K) {
    mu_ss <- (theta_A * (Y_bar/K - delta*K) * Y_bar) / (K^2 * (i_val + delta))
    return(dK_dt(K, mu_ss))
  }

  # Finde Steady State K_star in einem weiten Intervall
  K_star <- uniroot(ss_eq, interval = c(0.1, 5.0))$root
  mu_star <- (theta_A * (Y_bar/K_star - delta*K_star) * Y_bar) / (K_star^2 * (i_val + delta))

  # Jacobi-Matrix für Sattelpfad
  eps <- 1e-6
  J11 <- (dK_dt(K_star + eps, mu_star) - dK_dt(K_star, mu_star)) / eps
  J12 <- (dK_dt(K_star, mu_star + eps) - dK_dt(K_star, mu_star)) / eps
  J21 <- (dmu_dt(K_star + eps, mu_star) - dmu_dt(K_star, mu_star)) / eps
  J22 <- (dmu_dt(K_star, mu_star + eps) - dmu_dt(K_star, mu_star)) / eps

  J <- matrix(c(J11, J21, J12, J22), nrow = 2)
  ev <- eigen(J)
  beta <- (ev$values[which(ev$values < 0)] - J11) / J12

  ode_model <- function(t, state, parms) {
    K <- state["K"]
    mu <- mu_star + beta * (K - K_star)
    list(c(dK_dt(K, mu)))
  }

  out <- ode(y = c(K = K_0), times = seq(0, T_max, by = 0.1), func = ode_model, parms = NULL)

  df <- as.data.frame(out) %>%
    mutate(mu = mu_star + beta * (K - K_star), Typ = label, KI = "Mit KI")

  df$E <- get_E_constr(df$K, df$mu)
  df$A <- get_A_constr(df$K, df$E)
  df$X <- df$E + df$A
  df$Y <- df$K * df$X
  df$U <- log(df$Y) - 0.5 * theta_E * (df$E^2) - 0.5 * theta_A * (df$A^2)

  return(df)
}

get_E_noKI <- function(mu, t_E) {
  a <- t_E; b <- -mu; c <- -1
  (-b + sqrt(b^2 - 4 * a * c)) / (2 * a)
}

sim_noKI_free <- function(i_val, label, T_max = 30) {
  ss_eq <- function(mu) get_E_noKI(mu, theta_E) - (delta / ((i_val + delta) * mu))
  mu_star <- uniroot(ss_eq, interval = c(0.001, 10))$root
  K_star  <- 1 / ((i_val + delta) * mu_star)

  dE_dmu <- (get_E_noKI(mu_star + 1e-6, theta_E) - get_E_noKI(mu_star, theta_E)) / 1e-6
  J <- matrix(c(-delta, 1/(K_star^2), dE_dmu, i_val + delta), nrow = 2)
  ev <- eigen(J)
  beta <- (ev$values[which(ev$values < 0)] - (-delta)) / dE_dmu

  ode_model <- function(t, state, parms) {
    K <- state["K"]
    mu <- mu_star + beta * (K - K_star)
    dK <- get_E_noKI(mu, theta_E) - delta * K
    list(c(dK))
  }

  out <- ode(y = c(K = K_0), times = seq(0, T_max, by = 0.1), func = ode_model, parms = NULL)
  df <- as.data.frame(out) %>% mutate(mu = mu_star + beta * (K - K_star), Typ = label, KI = "Ohne KI", A = 0)
  df$E <- sapply(df$mu, get_E_noKI, t_E = theta_E)
  df$X <- df$E; df$Y <- df$K * df$X
  df$U <- log(df$Y) - 0.5 * theta_E * (df$E^2)
  return(df)
}

library(deSolve)
library(dplyr)
library(ggplot2)
library(tidyr)

# Globale Modellparameter
theta_E <- 1.0      # Arbeitsleid Eigene Anstrengung
theta_A <- 0.2      # Arbeitsleid KI-Nutzung (geringer als theta_E)
delta   <- 0.05     # Abschreibungsrate des Humankapitals
K_0_low <- 2.0      # Geringes Startkapital für Starthilfe-Szenario
Y_bar   <- 4.0      # Moderates Mindestoutput-Niveau

# ------------------------------------------------------------------------------
# Funktion für den freien Sattelpfad (Approximation der optimalen Regel)
# ------------------------------------------------------------------------------
get_free_policy <- function(K, i) {
  # Langfristige Gleichgewichtswerte im freien Regime
  E_star <- sqrt((i + 2 * delta) / (theta_E * (i + delta)))
  K_star <- E_star / delta
  
  # Linearisierte Policy-Funktion für Anstrengung und KI im freien Steigflug
  E_free <- pmax(0.1, E_star + 0.3 * (K_star - K))
  A_free <- pmax(0.1, 1 / (theta_A * (E_free + 1e-5))) 
  Y_free <- K * (E_free + A_free)
  
  return(list(E = E_free, A = A_free, Y = Y_free))
}

# ------------------------------------------------------------------------------
# Kuhn-Tucker ODE-Engine mit dynamischer Schlupfprüfung
# ------------------------------------------------------------------------------
sim_KT_regime <- function(i_val, K_init, label, T_max = 40) {
  
  ode_kt <- function(t, state, parms) {
    K <- state["K"]
    
    # 1. Was würde der Agent freiwillig tun?
    free <- get_free_policy(K, i_val)
    
    # 2. Kuhn-Tucker-Prüfung: Ist die Restriktion bindend?
    if (free$Y >= Y_bar) {
      # Regime A: Freie Optimierung (Hürde ist inaktiv, lambda = 0)
      E_t <- free$E
    } else {
      # Regime B: Bindender Mindestoutput (lambda > 0)
      # Kostenminimale Erfüllung von Y_bar bei gegebenem K
      E_t <- (theta_A / (theta_A + theta_E)) * (Y_bar / K)
    }
    
    dK <- E_t - delta * K
    list(c(dK))
  }
  
  times <- seq(0, T_max, by = 0.1)
  out <- ode(y = c(K = K_init), times = times, func = ode_kt, parms = NULL)
  
  df <- as.data.frame(out) %>% 
    mutate(Typ = label)
  
  # Werte für E, A, Y und Regime-Flag rekonstruieren
  df$E <- NA
  df$A <- NA
  df$Y <- NA
  df$Regime <- NA
  
  for (r in 1:nrow(df)) {
    K_curr <- df$K[r]
    free <- get_free_policy(K_curr, i_val)
    
    if (free$Y >= Y_bar) {
      df$E[r] <- free$E
      df$A[r] <- free$A
      df$Y[r] <- free$Y
      df$Regime[r] <- "Freier Steigflug (lambda = 0)"
    } else {
      df$E[r] <- (theta_A / (theta_A + theta_E)) * (Y_bar / K_curr)
      df$A[r] <- (theta_E / (theta_A + theta_E)) * (Y_bar / K_curr)
      df$Y[r] <- Y_bar
      df$Regime[r] <- "Bindende Hürde (lambda > 0)"
    }
  }
  
  return(df)
}

# Data-Prep für ggplot

    select(time, K, E, A, Y, Typ, Regime) %>%
    pivot_longer(cols = c(K, E, A, Y), names_to = "Variable", values_to = "Wert") %>%
    mutate(Variable = factor(Variable, levels = c("K", "E", "A", "Y")))
}

facet_labels <- c(K = "Humankapital (K)", E = "Eigene Anstrengung (E)", 
                  A = "KI-Nutzung (A)", Y = "Output (Y)")

# ==============================================================================
# SIMULATIONEN & PLOTTING
# ==============================================================================

# Szenario 1: Der geduldige Student (niedriges i = 0.03) mit Starthilfe-Effekt
df_patient <- sim_KT_regime(i_val = 0.03, K_init = K_0_low, label = "Geduldig (i = 0.03)")

p4 <- ggplot(prep_kt_plot(df_patient), aes(x = time, y = Wert, color = Regime)) +
  geom_line(linewidth = 1.3) +
  geom_hline(data = data.frame(Variable = factor("Y", levels = c("K", "E", "A", "Y")), val = Y_bar),
             aes(yintercept = val), linetype = "dashed", color = "black", alpha = 0.6) +
  facet_wrap(~ Variable, scales = "free_y", ncol = 2, labeller = as_labeller(facet_labels)) +
  scale_color_manual(values = c("Bindende Hürde (lambda > 0)" = "#d95f02", 
                                "Freier Steigflug (lambda = 0)" = "#1b9e77")) +
  labs(title = "Panel 4: Der Starthilfe-Effekt beim geduldigen Studenten",
       subtitle = "Erfolgreicher Lift-Off von der Mindestoutput-Hürde in die freie Optimierung",
       x = "Zeit (t)", y = "Niveau", color = "Kuhn-Tucker Regime") +
  theme_minimal(base_size = 13) +
  theme(legend.position = "bottom", 
        plot.title = element_text(face = "bold", size = 15),
        strip.text = element_text(face = "bold"))

print(p4)
